Key Components by Module
=========================

CORE (Platform-Independent):
  • Opus encoding/decoding (Concentus library)
  • Ogg container read/write (RFC 7845)
  • Noise detection algorithm
  • Audio configuration
  • Event data models

DESKTOP (JavaFX):
  • Record from microphone
  • Open .opus files
  • Display events list
  • Play event segments
  • Progress indicators

ANDROID (Native):
  • Foreground service recording
  • Screen-locked recording (wake lock)
  • Runtime permissions
  • File picker integration
  • Material Design UI
